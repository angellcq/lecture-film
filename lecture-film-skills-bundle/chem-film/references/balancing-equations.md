# 配平校验速查（math balance 模式）

## 基本用法

```json
{
  "kind": "balance",
  "label": "醋酸中和氢氧化钠",
  "equation": "CH3COOH + NaOH -> CH3COONa + H2O",
  "expect": {
    "CH3COOH": 1,
    "NaOH": 1,
    "CH3COONa": 1,
    "H2O": 1
  }
}
```

- `equation`：化学方程式，反应物 → 生成物，用 `->` 或 `=` 分隔
- `expect`：各物质的系数（可选，不写则只判定"可配平"）

## 方程式写法规则

| 规则 | 示例 |
|---|---|
| 反应物和生成物用 `->` 分隔 | `H2 + O2 -> H2O` |
| 多个物质用 `+` 分隔 | `2H2 + O2 -> 2H2O` |
| 下标直接写数字 | `H2O`、`CO2`、`H2SO4` |
| 系数写在分子式前面 | `2H2O`（但通常只写分子式，系数由校验得出） |
| 离子电荷用上标字符 | `H⁺`、`OH⁻`、`SO₄²⁻` |

## 原理

1. 解析每个分子式，提取元素及其个数
2. 构造元素矩阵（行=元素，列=物质）
3. 求零空间（系数向量），归一到最小整数
4. 与 `expect` 对比（如果提供了的话）

## 常见可配平但易写错的

| 方程式 | 正确系数 |
|---|---|
| `H2 + O2 -> H2O` | 2, 1 → 2 |
| `Fe + O2 -> Fe2O3` | 4, 3 → 2 |
| `Al + HCl -> AlCl3 + H2` | 2, 6 → 2, 3 |
| `CH4 + O2 -> CO2 + H2O` | 1, 2 → 1, 2 |
| `C2H5OH + O2 -> CO2 + H2O` | 1, 3 → 2, 3 |

## 不可配平的情况

- 元素不守恒（反应物有而生成物没有，或反过来）
- 电荷不守恒（离子方程式）
- 氧化还原电子不守恒

校验会直接失败并报告哪里不对。

## ⚠️ 注意

- 目前只支持**分子式**配平，不支持离子方程式的电荷配平
- 复杂有机化合物的分子式要写全（如 `CH3COOH` 而不是 `C2H4O2`，虽然两者元素一样）
- 水一律写 `H2O`，别写 `HOH`
